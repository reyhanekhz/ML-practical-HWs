This repository contains my solutions to the **practical homework assignments** for the *Machine Learning* course (Fall 2025).  
Each homework explores a fundamental area of machine learning – from classical regression to modern deep learning and NLP.


## Overview

| Folder | Topics / Algorithms | Key Libraries |
|--------|----------------------|----------------|
| **HW1 – Regression & Perceptron** | Linear regression, logistic regression, perceptron algorithm, evaluation metrics | `numpy`, `matplotlib`, `scikit-learn` |
| **HW2 – GMM, K-Means & PCA** | Gaussian Mixture Models (GMM), K‑means clustering, Principal Component Analysis (PCA) | `numpy`, `scikit-learn`, `scipy` |
| **HW3 – Neural Networks & Optimization** | MLP, backpropagation, activation functions, optimizers (SGD, Adam), regularization | `numpy`, `matplotlib`, `tensorflow`/`keras` or `pytorch` |
| **HW4 – CNN** | Convolutional layers, pooling, CNN architectures (e.g., LeNet, ResNet), image classification | `tensorflow`/`keras`, `pytorch`, `matplotlib` |
| **HW5 – NLP** | Text preprocessing, bag-of-words, TF‑IDF, word embeddings (Word2Vec/GloVe), sentiment analysis | `nltk`, `gensim`, `scikit-learn`, `tensorflow` |
